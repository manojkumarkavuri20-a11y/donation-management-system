# 📦 Donation Management System — Self-Initiated Portfolio Project

> **Portfolio project built for learning purposes. Modelled on a grassroots donation collection point of the type I supported during my internship at Care4Calais. The figures below are modelled estimates from the process redesign itself, not measured results from a live rollout — the system was not formally deployed.**

Process design exercise: replacing ad-hoc, informal donation operations with a structured, scalable logistics framework — covering donation intake, storage, volunteer coordination, and stakeholder reporting.

Developed as part of an MSc International Business Management (Distinction) portfolio, this project demonstrates process improvement design using practical tools accessible to non-profit organisations.

## 🎯 Project Overview

This project documents a proposed operational redesign of a grassroots donation management process, modelled on the type of operation I supported during my internship at Care4Calais. It is a self-initiated design exercise, not a delivered client engagement — the system was not formally implemented or measured in a live setting.

## 🏗️ 5-Area Improvement Framework

The design addresses five core operational areas:

1. **Donation Intake** — Standardised intake forms and categorisation
2. **Storage Management** — Zone-based storage with audit trails
3. **Volunteer Coordination** — Role definitions, training guides, and shift scheduling
4. **Donor Communication** — Templates for acknowledgement and updates
5. **Reporting & Analytics** — Excel dashboards for real-time visibility

## 📊 Modelled Effect of the Redesign

These are estimates derived from the process design itself (based on removing duplicated handling and moving preparation ahead of collection), not measured results from a live rollout:

| Area | Modelled Effect |
|---|---|
| Donation intake processing time | Roughly 35 → 12 minutes |
| Dispatch preparation time | Roughly 45 → 10 minutes |
| Item retrieval time | Roughly 15 → 4 minutes |
